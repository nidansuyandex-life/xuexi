# 日常 Daily

一个把「学英语、学阀门、练逻辑、练表达、看世界」装进同一个手机应用的个人成长工具。

## 功能

- **学习**：英语单词（听音写中文）、阀门专业知识（500+ 条）、通识知识、表达训练、周测
- **工作**：AI 办公（邮件/合同/Excel/翻译）、工作记录、一键加入学习计划
- **发现**：今日世界（新闻 + 我的思考）、分类推荐（书/电影/播客/工具）
- **我的**：今日打卡、本周回顾、成长记录、内容导入、语音设置、数据备份

## 特色

- **AI 评分**：复习时写下答案，AI 判分并给出工程师补充和记忆关键词
- **Anki 式复习**：完全不会 / 模糊 / 熟练 三档，自动安排下次复习时间
- **全局搜索**：知识、笔记、单词、新闻、AI 对话一次命中
- **PWA**：可添加到手机桌面，离线可用
- **数据本地**：所有内容存在浏览器，不上传服务器

## 使用

### 直接访问

打开：`https://<你的用户名>.github.io/daily/`

### 安装到手机桌面

**Android（Chrome）**
1. 打开上面的网址
2. 右上角菜单 → 「安装应用」或「添加到主屏幕」
3. 桌面会出现「日常」图标

**iOS（Safari）**
1. 打开上面的网址
2. 点底部分享按钮
3. 选择「添加到主屏幕」
4. 桌面会出现「日常」图标

### 配置 AI（可选）

不配置也能用（本地关键词判分），配置后 AI 会：
- 对复习答案给出更准确的评分
- 给出工程师补充和记忆关键词
- 对表达练习给出改进版本
- 作为 AI 助手回答阀门、工作、任何问题

推荐用 DeepSeek：去 `api.deepseek.com` 注册，拿 API Key，
在 App 里「我的 → AI 助手配置」填入即可。API Key 只存在本机浏览器。

## 技术

- 纯前端，单文件 HTML + 少量静态资源
- 无构建、无依赖、无后端
- 数据存储：localStorage
- 离线：Service Worker
- 图标：内联 SVG
